# 研发部会议纪要

## 2026 年 Q4 技术分享计划

研发部每两周举办一次技术分享会，时间固定在周五下午 16:00-17:30，地点 3 楼会议室 A。

### 分享主题安排

1. 第一期（11 月第 2 周）：Spring AI 2.0 与 Agent 开发实践 —— 主讲人：架构组
2. 第二期（11 月第 4 周）：RAG 系统的检索优化与效果评估 —— 主讲人：数据组
3. 第三期（12 月第 2 周）：大模型网关与多模型路由设计 —— 主讲人：平台组

## 知识库建设规范

1. 各组整理的技术文档统一放入部门知识库，格式推荐 Markdown 或 PDF；
2. 文档命名规范：日期_主题_作者，例如 20261113_SpringAI实践_张三.md；
3. 涉密文档严禁上传知识库，违者按保密条例处理。
